# 考研英语阅读生词记忆器

一个**纯本地运行**的间隔重复（SRS）背词工具。为「考研英语一阅读理解」这个具体目标做了取舍：

- **英→中再认优先**，不强迫拼写。阅读考的是「看到能反应出意思」，不是「能默写」
- 每张卡带**真题来源年份**、音标、词根词缀、同根词、柯林斯星级、双语例句
- 单独做了**形近词辨析**训练。阅读失分的主要来源往往不是「没见过」，而是形近词之间互相串（`contend / extend`、`adopt / adapt`、`process / progress / proceed`）
- **态度词**单独成组并标注正/负/中性，直接对应阅读的态度题

数据全部存在你自己的浏览器里。不联网、不上传、不需要注册。

## 在线使用

打开 **https://wzmyls.github.io/kaoyan-reading-vocab/** 即可。

手机、平板、电脑都能用，进度各自独立保存在本机浏览器中。

> 进度是按「访问地址」分别保存的：`localhost` 和线上地址各存一份。
> 想在两者之间搬进度，用统计页的「导出备份 / 导入备份」。

## 本地使用

Windows：双击 `启动.bat`，会自动起一个本地小服务并打开浏览器。

其他系统：

```bash
python -m http.server 8777
# 然后访问 http://127.0.0.1:8777
```

> 不要直接用 `file://` 打开 `index.html`。部分浏览器会禁止本地页面保存进度，
> 那样每次打开都会从头开始。

## 怎么用

四个页面：

| 页面 | 用途 |
|---|---|
| **背诵** | 每天的主线。正面是单词 + 挖空的例句，先自己回忆，按空格翻面，再评分 |
| **辨析** | 形近词抽题。给中文意思，从几个长得像的词里选，答完摊开全组对照。每天 5 分钟 |
| **词表** | 全部卡片。可搜索、按状态筛选、标记掌握、直接加新词 |
| **统计** | 倒计时、阶段安排、14 天复习量预测、28 天打卡热力图、按年份掌握度、导出/导入备份 |

键盘操作：`空格` 翻面，`1 2 3 4` 评分（忘记 / 模糊 / 认识 / 太简单）。

## 调度算法

Anki 简化版。间隔按「认识」约 ×2.5 增长：`1天 → 3天 → 8天 → 20天 → 50天 → 125天`。

- **忘记**：间隔砍到 20%，易度下调，退回学习阶梯，1 分钟后再考一次
- **模糊**：间隔只涨 20%，易度下调
- **认识**：间隔 × 易度因子
- **太简单**：额外 ×1.3，易度上调

间隔 ≥ 21 天算「已掌握」，上限 365 天，并带 ±5% 随机抖动，
避免同一天录入的词永远撞在同一天到期。

算法层是纯函数、不碰 DOM，见 [`assets/srs.js`](assets/srs.js)。

```bash
node tools/test_srs.js     # 算法测试（24 项）
node tools/test_app.js     # 界面渲染与交互冒烟测试（38 项）
```

## 换成你自己的词表

两种方式：

**方式一：在网页里加词。** 词表页点「＋ 加词」，随手添加，存在本地浏览器里。适合边做真题边补。

**方式二：重建整个词表。** 你自己的生词表整理成文本（每行 `单词 + 中文释义`，可带 `年份` 分节），然后：

```bash
python tools/parse_list.py      # 解析词表文本 -> raw/词表.json
python tools/fetch_dict.py      # 查词典补音标/释义/词根/例句（带缓存，只查新增的）
python tools/build_deck.py      # 合并生成 data.js
```

解析脚本对格式很宽容：能识别 `word中文释义`、`word 中文`、按年份分节、`{a, b, c}` 形式的易混词组，
并会自动去重、把 `imposed / sanctions / sold` 这类词形还原到原形。

`tools/manual.json` 是人工校正层，用来修正释义、补充易混词辨析、标注态度词极性。

- **词表来源**：本仓库自带的 `data.js` 是我自己整理的 2012–2020 考研英语一阅读生词表（282 张卡）。
- **词典内容**：释义、音标、词根词缀、双语例句通过公开词典接口批量获取，**仅供个人学习使用**。

- **真题原文**：本仓库不包含考研真题原文。例句来自词典语料，不是真题原句。
