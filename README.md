# 考研英语阅读生词记忆器

一个**纯本地运行**的间隔重复（SRS）背词工具。为「考研英语一阅读理解」这个具体目标做了取舍：

- **英→中再认优先**，不强迫拼写。阅读考的是「看到能反应出意思」，不是「能默写」
- 每张卡带**真题来源年份**、音标、词根词缀、同根词、柯林斯星级、双语例句
- 单独做了**形近词辨析**训练。阅读失分的主要来源往往不是「没见过」，而是形近词之间互相串（`contend / extend`、`adopt / adapt`、`process / progress / proceed`）
- **态度词**单独成组并标注正/负/中性，直接对应阅读的态度题
- **自己加词**：输入单词自动查内置词典（音标、释义、词根、近义辨析），选一个年份加进去；支持整列粘贴
- **自定义学习计划**：给一个目标日期，自动反推每天要学几个新词，并给出每周进度节点

数据全部存在你自己的浏览器里。不联网、不上传、不需要注册。

## 在线使用

打开 **https://wzmyls.github.io/kaoyan-reading-vocab/** 即可。

手机、平板、电脑都能用，进度各自独立保存在本机浏览器中。

> 进度是按「访问地址」分别保存的：`localhost` 和线上地址各存一份。
> 想在两者之间搬进度，用统计页的「导出备份 / 导入备份」。

## 本地使用

Windows：双击 `启动.bat`，会自动起一个本地小服务并打开浏览器。

其他系统：

```bash
python -m http.server 8777
# 然后访问 http://127.0.0.1:8777
```

> 不要直接用 `file://` 打开 `index.html`。部分浏览器会禁止本地页面保存进度，
> 那样每次打开都会从头开始。

## 怎么用

四个页面：

| 页面 | 用途 |
|---|---|
| **背诵** | 每天的主线。正面是单词 + 挖空的例句，先自己回忆，按空格翻面，再评分 |
| **辨析** | 形近词抽题。给中文意思，从几个长得像的词里选，答完摊开全组对照。每天 5 分钟 |
| **词表** | 全部卡片。可搜索、按状态筛选、标记掌握、直接加新词 |
| **统计** | 自定义学习计划、倒计时、阶段安排、14 天复习量预测、28 天打卡热力图、按年份掌握度、导出/导入备份 |

键盘操作：`空格` 翻面，`1 2 3 4` 评分（忘记 / 模糊 / 认识 / 太简单）。

## 加自己的生词（带年份）

「词表」或「背诵」页点 **＋ 加词**：

1. 选一个年份（决定它归到哪一年，以及按年份统计的口径）
2. 粘贴单词，一行一个；也支持 `单词 中文` 的格式，或一行多个用逗号隔开
3. 点「查词典」——自动补上音标、释义、词根词缀、近义辨析、考试标签
4. 释义可以直接在表格里改（词典释义偏旧，以你自己的理解为准）
5. 保存，立刻进入背诵队列

词典里查不到的词也能存，手填一个释义就行。输入复数或变形（`sanctions`）会自动归到原形
（`sanction`）；如果原形早已在词表里，会标成「词表已有」，不会重复添加。

## 自定义学习计划

统计页顶部。设定**目标日期**和**考前留出几天只复习**，点「生成计划」：

- 按剩余新词反推每天要学几个（例：剩 263 个词、可学 22 天 → 每天 12 个）
- 显示每天大概要花多少分钟、新词铺开后的每日复习量
- 给出**每周节点**：到这一周结束应该累计学完多少、还剩多少
- 「按这个计划设置」一键改掉每天新词数与考试日期

目标定得太紧（每天超过 30 个新词）会给出提醒。

## 调度算法

Anki 简化版。间隔按「认识」约 ×2.5 增长：`1天 → 3天 → 8天 → 20天 → 50天 → 125天`。

- **忘记**：间隔砍到 20%，易度下调，退回学习阶梯，1 分钟后再考一次
- **模糊**：间隔只涨 20%，易度下调
- **认识**：间隔 × 易度因子
- **太简单**：额外 ×1.3，易度上调

间隔 ≥ 21 天算「已掌握」，上限 365 天，并带 ±5% 随机抖动，
避免同一天录入的词永远撞在同一天到期。

算法层是纯函数、不碰 DOM，见 [`assets/srs.js`](assets/srs.js)。

```bash
node tools/test_srs.js     # 算法测试（41 项）
node tools/test_app.js     # 界面渲染与交互测试（65 项，含真实的词典查询链路）
```

## 内置词典

「加词」用的词典是把 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT 许可）裁剪出来的：
从 77 万条里保留考试大纲词汇、柯林斯/牛津核心词和高频词，共 **3.1 万条**，
音标统一成 IPA，按哈希切成 16 个分片按需加载（每次查询只下载约 240KB，之后缓存在浏览器里）。
词根表和近义辨析表单独放在 `dict/ecdict-aux.js`，首次加词时才加载。

重新生成词典：

```bash
python tools/build_dict.py --src <ECDICT 源码目录>   # 输出到 dict/
```

词典数据的许可见 [`dict/ECDICT-LICENSE.txt`](dict/ECDICT-LICENSE.txt)。

## 换成你自己的词表

两种方式：

**方式一：在网页里加词。** 见上面「加自己的生词」，适合边做真题边补。

**方式二：重建整个词表。** 你自己的生词表整理成文本（每行 `单词 + 中文释义`，可带 `年份` 分节），然后：

```bash
python tools/parse_list.py      # 解析词表文本 -> raw/词表.json
python tools/fetch_dict.py      # 查词典补音标/释义/词根/例句（带缓存，只查新增的）
python tools/build_deck.py      # 合并生成 data.js
```

解析脚本对格式很宽容：能识别 `word中文释义`、`word 中文`、按年份分节、`{a, b, c}` 形式的易混词组，
并会自动去重、把 `imposed / sanctions / sold` 这类词形还原到原形。

`tools/manual.json` 是人工校正层，用来修正释义、补充易混词辨析、标注态度词极性。

- **词典内容**：`data.js` 里的释义、音标、词根词缀、双语例句通过公开词典接口批量获取，**仅供个人学习使用**。
